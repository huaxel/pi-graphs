- Prune confirmation copy. `/charts prune` counts chart stems and calls them folders (`index.ts`, the confirm string). The day cutoff and the delete are correct. Not worth a plan.
- The mpl git pin (`github:ivarvong/mpl#117503c`). The README and `test/mpl-contract.test.ts` treat the pin as intentional. CI on `a8b5b60` passed. `npm audit` reported no advisories.
- Arbitrary paths in `$csv`, `$json`, and `from`. This is a local agent tool that reads the files the agent names.
- HTML injection through chart labels. mpl escapes SVG text.
- A linter, `AGENTS.md`, or a `LICENSE` file. Setup is already in the README. There is no `LICENSE` file if GitHub should display MIT. None of that blocks the bugs above.
- Migrating spec JSON that already has Pi theme keys baked in. Plan 004 stops new renders from writing those keys. Old files still restyle only as far as the baked rc allows. Re-render from the original calls for a clean spec.
